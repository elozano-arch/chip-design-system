Empty states

El mensaje que ve el usuario cuando una tabla no tiene filas. Hay tres situaciones distintas y cada una usa su propio icono y texto — no son intercambiables. Se renderizan en el template #emptymessage de p-table.

Cuándo usar cada estado

SituaciónIconoMensaje
Aún no se ha buscadopi-search"Use los filtros y presione Buscar…"
Se buscó pero no hay coincidenciaspi-inbox"No se encontraron resultados…"
Nunca ha habido datospi-inbox + acción"Aún no hay registros. Crea el primero."

Error frecuente: usar pi-inbox ("sin resultados") cuando en realidad el usuario todavía no ha buscado. Si la búsqueda es manual, el estado inicial va con pi-search.

01

Estado inicial — aún no se ha buscado

Pantallas donde la consulta es manual (hay que presionar Buscar). Invita a usar los filtros, no dice "sin resultados".

Use los filtros y presione Buscar para listar usuarios.

02

Sin resultados — se buscó y no hubo coincidencias

El caso más común: hay filtros aplicados pero ninguna fila coincide. Icono pi-inbox y mensaje uniforme.

No se encontraron resultados para los filtros aplicados.

03

Sin datos — lista que nunca ha tenido registros

Cuando la entidad aún no tiene ningún registro. Además del mensaje, ofrece la acción para crear el primero.

Aún no hay registros.
