Badges y tags de estado

Etiquetas de estado sobre p-tag, contadores con p-badge y chips removibles con p-chip. La regla central: el color comunica el significado, no el texto — y ese mapeo debe ser el mismo en todas las pantallas.

Mapa canónico estado → color

Antes había ambigüedad (p. ej. info usado tanto para metadato como para pendiente). Este es el mapeo único que toda pantalla debe seguir:

@for (m of mapa; track m.estado) { }

{{ m.estado }} {{ m.severity }} {{ m.uso }}

No uses el mismo color para significados distintos. Si un estado nuevo no encaja en estos 5, valídalo con el equipo antes de inventar un color.

01

Tags de estado (p-tag)

El uso principal: marcar el estado de un registro en una tabla o ficha. Texto corto + color según el mapa.

02

Tag con severity calculada

En tablas, la severity se deriva del estado con un método único, para no repetir el mapeo a mano en cada celda.

Variante [rounded]="true" (píldora) — elige una forma y mantenla en toda la app.

Contadores (p-badge)
