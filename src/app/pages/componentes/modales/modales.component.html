Modales

Ventanas de diálogo sobre p-dialog de PrimeNG. Define qué debe llevar todo modal del sistema y sus variantes: confirmación destructiva, formulario CRUD y selección. Alineado con el Kit UI 9.2 GOV.CO.

Qué debe llevar un modal

Modal y no arrastrable

[modal]="true", [draggable]="false" y [closeOnEscape]="true" siempre.

Ancho contenido

Confirmaciones ≈ 460px · formularios 520–720px. Nunca fullscreen para un diálogo.

Footer ordenado

Cancelar ([text] secondary) a la izquierda, acción principal a la derecha. La confirmación pesa más que el rechazo.

Mensaje claro

Header descriptivo ("Eliminar usuario"), cuerpo directo y, en destructivas, advertencia explícita de irreversibilidad.

01

Confirmación destructiva

Para eliminar o revertir. Icono de alerta, mensaje de irreversibilidad y footer con Cancelar + acción danger.

02

Confirmación crítica (escribir ELIMINAR)

Variante para eliminaciones irreversibles de alto impacto: el botón se habilita sólo cuando el usuario escribe ELIMINAR. Previene clics accidentales.

03

Formulario CRUD

Crear o editar un registro. Hint de campos obligatorios, grid de campos con label + field-required, footer Cancelar + Guardar.

04

Selección (radio buttons)

Elegir una opción de una lista corta dentro del modal (ej. correo de verificación). role="radiogroup" y acción deshabilitada hasta elegir.
