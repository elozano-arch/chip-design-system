Data Table

Tabla de datos estándar sobre p-table de PrimeNG. Define qué debe llevar toda tabla del sistema y sus variantes: con paginador, sin paginador, scroll horizontal con muchas columnas, tooltip en celdas y estado vacío. Alineado con el Kit UI 9.2 GOV.CO.

Qué debe llevar un data table

Filas legibles

[stripedRows]="true" + [rowHover]="true" para diferenciar filas y dar feedback al pasar el cursor.

Paginador con reporte

[rows]="10", [rowsPerPageOptions]="[5,10,25]" y currentPageReportTemplate "Mostrando {{ '{' }}first{{ '}' }} a {{ '{' }}last{{ '}' }} de {{ '{' }}totalRecords{{ '}' }}".

Caption para lectores

Una #caption con texto sr-only que describe la tabla. Obligatoria por accesibilidad.

Estado vacío

Template #emptymessage con pi-inbox y mensaje uniforme cuando no hay resultados.

Columna de acciones

Última columna "Acciones": icon-only (F7) o menú contextual "…" (F8) según cuántas acciones haya.

01

Estándar con paginador (de filas)

El caso por defecto para cualquier listado. Paginador de filas (lo que Cris llama "paginador de grillas") con selector de cuántas mostrar y reporte de página.

02

Sin paginador (lista corta)

Cuando los registros caben de un vistazo (≈ ≤ 10 filas fijas), se omite el paginador y el reporte de página para no agregar ruido.

03

Muchas columnas — scroll horizontal + columna congelada

A confirmar con Cris

Para tablas anchas: [scrollable]="true" con la primera columna congelada (pFrozenColumn), así el código siempre queda visible al desplazarse a la derecha. Posible interpretación de "paginador de columnas" — pendiente de que Cris confirme si se refiere a esto, a un toggle de visibilidad de columnas, o a otra cosa.
