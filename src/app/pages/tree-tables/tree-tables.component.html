Tree-tables

Catálogo del tree-table estándar del CHIP y sus 3 variantes funcionales, construidas sobre un único componente reutilizable <app-tree-table> config-driven. Cada variante activa o desactiva features (edición, menús, paginadores, selector de columnas) según el caso de uso, manteniendo el mismo comportamiento base.

Estándares aplicados

Decisiones acordadas con el equipo que el componente garantiza en todas sus variantes.

Las 3 variantes

V1

Consulta / Visualización

Solo lectura. Para reportes y consultas — sin edición.

V2

Editable / Formularios

Edición inline + barra sticky de cambios pendientes.

V3

Completa

Menús por fila + paginador de registros + selector de columnas.

V1

Consulta / Visualización

Tabla de solo lectura para reportes y consultas. Conserva la jerarquía, la búsqueda global y el paginador por nodo, pero no permite editar ni muestra barra de cambios. Es la base más liviana.

  • Búsqueda global
  • Paginador por nodo
  • Tags de estado
  • Sin edición
  • Sin menús ni column toggle
{{ snippets['V1'] }}
V2

Editable / Formularios

Tabla editable para captura tipo formulario. Click en una celda editable (marcada con lápiz) para editar inline; los cambios se acumulan en la barra sticky con acciones Guardar / Descartar.

  • Edición inline
  • Sticky bar de cambios
  • Búsqueda + paginador
  • Sin menús ni column toggle
{{ snippets['V2'] }}
V3

Completa

Variante todo incluido: añade menú contextual por fila (Ver, Editar, Duplicar, Eliminar), paginación horizontal de columnas y un selector de columnas (column toggle) para mostrar/ocultar columnas variables. Pensada para tablas con muchas columnas y acciones por registro.

  • Menú contextual por fila
  • Paginador de columnas (4 a la vez)
  • Column toggle
  • Edición + búsqueda + paginador
{{ snippets['V3'] }}

Requisito del consumidor

El componente emite mensajes (guardar, descartar, acciones de menú) vía MessageService. La pantalla que lo use debe proveer el servicio y renderizar un <p-toast /> propio (uno por pantalla, compartido entre instancias).
