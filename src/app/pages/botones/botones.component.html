Botones

Catálogo de botones del sistema agrupados en 14 familias funcionales. Cada familia define su severity, label, icono y ubicación canónicos. Construido sobre p-button de PrimeNG, alineado con el Kit UI 9.2 GOV.CO.

Buenas prácticas (Kit UI v9.2)

Color por importancia, no por verbo

El color comunica jerarquía y riesgo (cobalto = primaria, rojo = destructiva), no la acción literal del verbo.

Label e icono canónicos

Usar siempre los mismos labels/iconos para una misma acción (Guardar + pi-save, Eliminar + pi-trash).

Ubicación estándar

Crear/Descargar en header derecha. Limpiar+Buscar al pie de filtros. Acciones por fila en columna "Acciones".

Accesibilidad obligatoria

Icon-only siempre con pTooltip + aria-label. Focus visible. Navegación por teclado.

Una sola acción primaria

Por contexto sólo hay una primaria. Si hay dos botones en cobalto sólido juntos, alguno está mal clasificado.

Confirmación para destructivas

Eliminar / revertir siempre con modal de confirmación. El label en el modal debe ser explícito ("Sí, eliminar").

Cómo usar este catálogo

Modo A

Pantalla nueva

Eliges la familia que necesitas y aplicas el canon directamente. La función la decides tú al crear el botón — no hay nada que "clasificar".

Modo B

Normalización de pantalla existente

Identifica la función real de cada botón antes de tocar (Paso 0). Lista las excepciones legítimas para validar con un dev del equipo.

F1

Acción primaria

Ejecuta la acción principal del flujo: cierra modal con éxito, guarda formulario, confirma decisión. Una sola por contexto.

Severity
Cobalto sólido (default)
Labels
Guardar · Confirmar · Crear · Aceptar
Iconos
pi-save · pi-check · pi-plus
Ubicación
Header derecha · Footer modal derecha

F2

Acción secundaria

Abandonar / cancelar el flujo. Siempre acompaña a una primaria — la primaria a la derecha, la secundaria a la izquierda.

Severity
secondary + [text] o [outlined]
Labels
Cancelar · Cerrar
Iconos
Sin icono · pi-times
Ubicación
Footer modal izquierda · Pie de formulario izquierda
{{ snippets['F2'] }}
F3

Destructiva

Elimina, revierte, borra definitivamente. Siempre con confirmación explícita (modal). En modales, el label debe ser largo y claro ("Sí, eliminar").

Severity
severity="danger"
Labels
Eliminar · Sí, eliminar · Sí, revertir todos
Iconos
pi-trash · pi-undo (revertir)
Ubicación
Fila tabla (icon-only) · Footer modal confirmación
{{ snippets['F3'] }}
F4

Navegación de wizard

Avanza / retrocede en flujos multietapa. No es una acción primaria — es navegación. El último paso suele cambiar "Siguiente" por "Finalizar" o "Enviar".

Siguiente
Default cobalto · iconPos="right"
Anterior
secondary [outlined]
Iconos
pi-arrow-right · pi-arrow-left
Ubicación
Footer del paso · Anterior izquierda · Siguiente derecha
{{ snippets['F4'] }}
F5

Filtros (Limpiar + Buscar)

Par específico al pie del panel de filtros. "Buscar" en cobalto sólido, "Limpiar" en estilo más liviano para no competir visualmente.

Buscar
Default cobalto
Limpiar
secondary [outlined] o [text]
Iconos
pi-search · pi-filter-slash
Ubicación
Pie del panel de filtros (no en header)
{{ snippets['F5'] }}
F6

Descarga / exportación

Descarga un archivo (PDF, Excel, CSV, plantilla) o exporta datos. Cuando el formato es ambiguo, el label lo aclara ("Descargar PDF" mejor que "Descargar").

Severity
success · secondary [outlined] · icon-only en tabla
Labels
Descargar PDF/XLSX · Exportar
Iconos
pi-download · pi-file-pdf · pi-file-excel
Ubicación
Header derecha · Toolbar tabla · Fila tabla
{{ snippets['F6'] }}
F7

Icon-only en tabla

Acciones rápidas por fila. Tooltip y aria-label obligatorios — sin label visible, el tooltip es lo único que comunica la acción. Orden: Ver → Editar → especiales → Eliminar.

Estilo
[rounded] [text] siempre
Severity
Default (Ver) · success (Editar) · danger (Eliminar) · secondary (Descargar)
Iconos
pi-eye · pi-pencil · pi-trash · pi-download
Ubicación
Columna "Acciones" — última columna de la tabla
{{ snippets['F7'] }}
F8

Menú contextual

Abre un dropdown de acciones secundarias. Útil cuando hay más de 3-4 acciones por fila y los icon-only saturarían. Orden interno: principal → especiales → separador → destructiva.

Abre el selector de archivos para subir un documento. El label especifica qué archivo se espera ("Adjuntar RUT" mejor que "Adjuntar").

Severity
[outlined] default · secondary [outlined] opcional

Iconos

F10

Enviar / confirmación de acción

Distinto de F1 "Guardar". Guardar es local (mantiene el flujo); Enviar dispara la transacción y cierra el flujo. Si es irreversible, advertir en modal previo.

Severity
Default cobalto · success (refuerza completitud)
Labels
Enviar · Enviar reporte · Enviar al CHIP central
Iconos
pi-send · pi-paperclip (con adjunto)
Ubicación
Footer modal confirmación · Último paso de wizard
{{ snippets['F10'] }}
F11

Copiar al portapapeles

Acción auxiliar para copiar contenido técnico (código, HTML, ID). Estilo más liviano para no robar protagonismo del contenido que acompaña. Tras copiar, dar feedback visual (icono pi-check 2s o toast corto).

Severity
secondary [outlined]
Labels
Copiar código · Copiar HTML · Copiar enlace
Icono
pi-copy
Ubicación
Junto al bloque de contenido (esquina superior derecha)
{{ snippets['F11'] }}
F12

Accesibilidad (controles a11y)

Fuera del canon PrimeNG

Ajustan parámetros globales de accesibilidad. Son <button> nativos, no p-button — son parte del chrome global, no del flujo de la pantalla. Se rigen por WCAG 2.1 AA (Resolución 1519/2020).

Estilo
<button> nativo · clase .a11y-btn
Labels
Sin label visible · aria-label obligatorio
Estado
aria-pressed en toggles
Ubicación
Toolbar superior del header · Panel a11y flotante
{{ snippets['F12'] }}
F13

Floating buttons (servicio)

Fuera del canon PrimeNG

Acceso flotante a features auxiliares (chat, contacto, "volver arriba", panel a11y). Esquina inferior derecha, position: fixed. También <button> nativo.

Estilo
<button> nativo · clases floating-btn
Posición
position: fixed · esquina inferior derecha
Iconos
pi-comments · pi-envelope · pi-arrow-up
Accesibilidad
aria-label obligatorio · respetar orden focal
{{ snippets['F13'] }}
F14

Toggles de estado

Cambian entre dos estados. aria-pressed obligatorio para que screen readers comuniquen el estado. Label puede ser dinámico (Activar/Desactivar) o sólo icono (grid/lista).

Estilo
Activo sólido · inactivo [outlined] · severity según contexto
Labels
Dinámicos (Activar/Desactivar) · sin label (layout)
Estado
aria-pressed obligatorio
Ubicación
Panel detalle · Toolbar de vista · Headers expandibles

Excepciones legítimas

Al normalizar pantallas existentes, hay botones intencionalmente distintos del patrón general — wizards, confirmaciones destructivas con label largo, pares primaria+secundaria intencionales, botones nativos de accesibilidad y floating. No tocarlos sin validar con un dev. El catálogo completo de excepciones legítimas está en .claude/skills/chip-ui-rules/references/canon-botones.md.
