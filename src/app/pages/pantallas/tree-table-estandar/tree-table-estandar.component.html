Tree-table — Estándar

Comportamiento estandarizado del tree-table del CHIP. Reúne las decisiones tomadas con Wilmar e Inge Diego sobre paginación, expansión, edición y búsqueda.

Estándares aplicados en esta tabla

  • Una sola rama abierta a la vez (configurable). Al abrir otra rama del mismo nivel, se cierra la anterior para evitar scroll vertical excesivo.
  • Indicador visual del nodo activo con barra cobalto a la izquierda y miga de pan jerárquica para no perder el contexto.
  • Paginador por nodo padre con tamaños 5 / 10 / 25 / 50 y etiqueta "Mostrando X a Y de Z registros".
  • Paginación horizontal de columnas variables (4 columnas a la vez), dejando código y concepto fijos a la izquierda.
  • Edición inline (click en celda editable) + barra sticky con "N cambios pendientes" y acciones Guardar / Descartar.
  • Búsqueda global en todo el árbol por código o concepto. El árbol se colapsa a las ramas que contienen coincidencias.
